# Roadmap de Nucleus · Idle Lab

Este documento es el checklist vivo para llevar el prototipo a una versión jugable y publicable.

## 1. Onboarding renovable y transición térmica

- [x] Turbina eólica disponible desde el comienzo.
- [x] Panel solar desbloqueado mediante energía acumulada.
- [x] Producción renovable sin calor, combustible ni refrigeración.
- [x] Núcleo y componentes térmicos bloqueados hasta 750 MW.
- [x] Tutorial reordenado para enseñar renovables antes del calor.
- [x] Verificar la progresión completa en una partida nueva móvil.

## 2. Contratos y objetivos periódicos

- [x] Contratos persistentes de producción renovable, general y térmica.
- [x] Recompensas de créditos y ciencia.
- [x] Renovación al reclamar, sin vencimiento ni castigos por no participar.
- [x] Panel móvil compacto y persistencia/migración.

## 3. Mantenimiento predecible

- [x] Desgaste visible por componente.
- [x] Mantenimiento manual y automático configurable.
- [x] Penalización gradual de rendimiento, sin fallos aleatorios.
- [x] Costes y telemetría acumulada.

## 4. Tecnología y automatización

- [x] Batería eléctrica que almacena energía realmente desviada.
- [x] Controlador automático para una reserva objetivo de red.
- [x] Investigaciones para renovables, almacenamiento y mantenimiento.
- [x] Desbloqueos intermedios a 1.500 y 7.500 MW.

## 5. Sectores y reinversión

- [x] Segundo sector desbloqueable con una grilla propia.
- [x] Bonificaciones distintas por sector.
- [x] Reinversión/prestigio opcional con beneficio permanente.
- [x] Navegación mobile-first entre sectores.

## 6. Balance y progreso offline

- [x] Curva de hitos documentada y apertura renovable verificada.
- [x] Rentabilidad de combustible, mantenimiento y contratos cubierta por pruebas.
- [x] Simulación offline resumida, limitada y protegida ante explosiones.
- [x] Servicios automáticos sin deuda y rutas de recuperación disponibles.

## 7. Experiencia móvil y accesibilidad

- [x] Tutorial contextual plegable y con progreso accesible.
- [x] Estados bloqueados con explicación clara.
- [x] Objetivos táctiles amplios y controles nativos de teclado.
- [x] Pruebas visuales en 320, 390 y 768 px.

## 8. Robustez y PWA

- [x] Migraciones verificadas desde todas las versiones guardadas.
- [x] Recuperación segura con respaldo ante guardado corrupto.
- [x] Pruebas unitarias de economías, componentes y protecciones.
- [x] PWA offline verificada en Chromium e iconos compatibles con Safari.

## 9. Publicación

- [x] Inicializar repositorio Git y preparar un release local verificable.
- [ ] Configurar repositorio remoto elegido por el usuario.
- [ ] Publicar en GitHub Pages.
- [ ] Ejecutar smoke test de la URL publicada.

## Definición de terminado

La primera versión se considera completa cuando una partida nueva puede progresar desde eólica hasta fusión sin bloqueos, todos los sistemas tienen explicación táctil, guardado y offline sobreviven a migraciones, la suite automatizada pasa y existe una URL instalable como PWA.
